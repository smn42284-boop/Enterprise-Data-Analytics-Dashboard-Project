## Overview
This is a fictional enterprise data management system and analytics application designed for learning enterprise IT concepts including master data management, SQL, data quality, REST APIs, React, Python data processing, dashboards and ERP related business processes. 

## My project purpose 
This project simulates an internal business application used to manage **customers**, **products**, **vendors** and **sales transactions**. 
This project is educational and does not represent any real company's internal system data.
